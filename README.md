# Liang Wang 的个人主页

基于 [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) 构建的 Jekyll 个人主页，支持 GitHub Pages 自动部署。

## 本地预览

建议使用 Ruby 3.2 或更高版本：

```bash
bundle install
bundle exec jekyll serve --livereload
```

然后打开 <http://127.0.0.1:4000>。
